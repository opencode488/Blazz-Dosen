Saya ingin membangun sebuah website bernama **"Dosen Chat Bot"** menggunakan **React JS + Vite**.

Website ini merupakan dashboard mahasiswa untuk mengelola data dosen, mata kuliah, jadwal perkuliahan, dan mengirim pesan WhatsApp kepada dosen secara terjadwal.

## TEKNOLOGI UTAMA

### Frontend

* React JS
* Vite
* Tailwind CSS
* React Router DOM
* Axios
* Lucide React Icons

### Backend

* Node.js
* Express.js

### Database

* Supabase PostgreSQL

### AI

* AI API melalui backend

### WhatsApp

* WhatsApp Business Platform/API resmi atau provider WhatsApp resmi

### Scheduler

* Backend cron/scheduler
* Timezone: Asia/Jakarta (WIB)

Jangan menggunakan Next.js.
Jangan menggunakan Laravel.
Frontend harus benar-benar menggunakan React JS + Vite.

---

# 1. KONSEP WEBSITE

Website berfungsi sebagai **Student Communication Assistant**.

Mahasiswa dapat menyimpan:

* Nama dosen
* Nomor WhatsApp dosen
* Nama mata kuliah
* Tanggal kuliah
* Jam kuliah
* Ruang kelas
* Catatan

Kemudian sistem dapat membuat pesan kepada dosen.

Fitur utama:

**Auto Chat H-1**

Jika mata kuliah berlangsung pada:

Senin, 5 Oktober 2026
08.00 - 09.40

maka sistem menjadwalkan pesan:

Minggu, 4 Oktober 2026
08.00 WIB

Pesan dikirim ke nomor WhatsApp dosen.

# 15. AUTO CHAT LOGIC

Jika:

tanggal kuliah = 5 Oktober 2026

maka:

scheduled_at = 4 Oktober 2026 08:00 Asia/Jakarta

Jika:

tanggal kuliah = 6 Oktober 2026

maka:

scheduled_at = 5 Oktober 2026 08:00 Asia/Jakarta

Jika jadwal diubah, scheduled_at harus ikut berubah.

Jika jadwal dihapus:

scheduled message harus dibatalkan.

Jika Auto Chat OFF:

tidak membuat scheduled message.

# 19. SCHEDULER

Backend menjalankan scheduler menggunakan timezone:

Asia/Jakarta

Scheduler mengecek scheduled_messages.

Jika:

status = scheduled

dan

scheduled_at <= current time

maka:

1. Lock message.
2. Ambil nomor.
3. Ambil message.
4. Kirim melalui WhatsApp API.
5. Simpan provider_message_id.
6. Update status.

Status:

scheduled

processing

sent

failed

cancelled

Pastikan terdapat mekanisme idempotency sehingga pesan tidak terkirim dua kali.
